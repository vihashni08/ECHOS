# Components: detectors, agents and infrastructure

Generated by `scripts/make_components_doc.py` from `echos/components.py`; the API (`GET /api/components`) and the web app (How it works) read the same registry.

ECHOS watches the sensors and vital signs of one older person and tells their caregiver and clinician, at once when a fall or critical reading is detected, and once a day whether anything differs from that person's own usual. Decision support, not a diagnosis; a language model never decides an emergency.

## Detectors

Detector: senses and turns data into evidence. Never decides a status and never sends anything.

### Data Quality gate (`quality`)

Checks that the data can be trusted before anything is scored: ranges, silent sensors, gaps, freshness.

- **Takes in:** raw activity and vitals events
- **Produces:** quality verdict per patient-day (never imputes)
- **If it fails:** data passes through marked 'quality unchecked'; the day can never be NORMAL
- **Never:** fill in missing values

### Vitals + Behaviour detector (`health_monitoring`)

Compares blood pressure, heart rate and daily routine with the person's own usual (two separate models, with SHAP explanations).

- **Takes in:** cleaned vitals and activity
- **Produces:** flags with evidence (personal baseline, persistence)
- **If it fails:** fixed vitals thresholds are used and the day is marked 'monitoring degraded'
- **Never:** decide a status or send anything

### Fall detector (`fall`)

Detects a fall in a 2.5 s accelerometer window and checks for inactivity afterwards. Independent of the other detectors.

- **Takes in:** accelerometer windows
- **Produces:** fall probability + inactivity evidence
- **If it fails:** the supervisor restarts it; a fall that arrives meanwhile is delayed, not lost
- **Never:** use TIHM (it has no falls); decide an alert

## Agents

Agent: has a goal, chooses its next step, uses tools, acts and leaves a trace.

### Triage agent (`triage`)

Turns detector outputs into one status (Normal / Changed-monitor / Urgent) with plain if-then rules and opens the case.

- **Takes in:** detector outputs
- **Produces:** status, reasons, case
- **If it fails:** a day with missing detector output is a data gap, never Normal
- **Never:** use a learned model or an LLM to decide

### Case Investigator agent (`investigator`)

For every non-Normal case, plans and runs a few checks (history, agreement between detectors, data caveats) and writes the case file.

- **Takes in:** triage decision + detector outputs + history
- **Produces:** case file: headline, corroboration, trend, caveats, evidence level, trace of steps
- **If it fails:** the case still goes on without a case file
- **Never:** change the status or give medical advice

### Care Coordinator agent (`coordinator`)

Owns every alert until someone acts: tracks delivery, waits for acknowledgement, escalates to a second contact, opens check-in and review tasks.

- **Takes in:** alerts, outbox, acknowledgements, case history
- **Produces:** alert states, escalations, care tasks
- **If it fails:** alerts are already sent by the dispatcher; only escalation and tasks pause until it restarts (state is in the database)
- **Never:** delay or suppress the first alert

### Report agent (`report`)

Writes the daily caregiver report and the weekly clinician PDF from the case file; the LLM is optional and always checked by a non-LLM validator.

- **Takes in:** case file, facts, retrieved guidance
- **Produces:** daily report, weekly PDF, provenance
- **If it fails:** a template report is used
- **Never:** decide an emergency or put an LLM on the alert path

## Infrastructure

Infrastructure: keeps the others running.

### Supervisor (`supervisor`)

Starts the three detector workers, watches their heartbeats and restarts dead ones.

- **Takes in:** heartbeats
- **Produces:** restarts
- **If it fails:** dead workers stay dead until it is restarted
- **Never:** touch data

## How they talk

Agents hand cases over through the SQLite message bus (`agent_message`, `echos/team/bus.py`): Triage -> Case Investigator (`case_opened`), Case Investigator -> Care Coordinator and Report agent (`case_file_ready`), Care Coordinator -> everyone (`alert_escalated`). The web app shows the bus under *How it works* and the latest hand-overs on *Today*.
